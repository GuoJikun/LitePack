## 1. 需求概述

### 1.1 背景

当前 LitePack 仅支持一种右键菜单模式「直接解压」（解压到当前文件夹）。需要扩展为四种模式，对标主流压缩软件（如 360 压缩）的右键菜单体验。

### 1.2 目标

- 支持四种右键菜单动词
- 每种动词对应不同的 UI 交互模式
- 完成后自动退出（右键菜单场景）

---

## 2. 四种模式定义

### 2.1 模式对照表

| # | 菜单项 | 启动参数 | UI 模式 | 完成后行为 |
|---|--------|----------|---------|------------|
| 1 | 打开/浏览 | `--open "%1"` | 归档浏览器（现有） | 保持打开 |
| 2 | 解压到... | `--extract-to "%1"` | 解压对话框（新） | 自动退出 |
| 3 | 解压到当前文件夹 | `--extract-here "%1"` | 简化进度界面 | 自动退出 |
| 4 | 解压到同名目录 | `--extract-named "%1"` | 简化进度界面 | 自动退出 |

### 2.2 模式详细说明

#### 模式 1：打开/浏览（复用现有）

**行为：**
1. 启动应用，打开指定归档
2. 显示文件列表（归档浏览器）
3. 用户手动操作（搜索、解压等）

**UI：**
- TitleBar + Toolbar
- FileTable（文件列表）
- StatusBar

**启动参数：**
```
litepack.exe --open "E:\archive.zip"
```

---

#### 模式 2：解压到...（新对话框）

**行为：**
1. 启动应用，显示解压对话框
2. 目标路径默认填充归档所在目录
3. 用户可修改路径或点击 📁 选择文件夹
4. 显示目标磁盘剩余空间
5. 点击「立即解压」开始解压
6. 完成后自动退出

**UI：**
```
┌─────────────────────────────────────┐
│  解压文件                        [─][×]│
├─────────────────────────────────────┤
│  目标路径: [________________][📁]   │
│           剩余: 37.2GB             │
├─────────────────────────────────────┤
│  ▶ 高级选项        [立即解压]       │
└─────────────────────────────────────┘
```

**启动参数：**
```
litepack.exe --extract-to "E:\archive.zip"
```

**高级选项（待办）：**
- 压缩等级选择
- 覆盖模式（跳过/覆盖/询问）
- 跳过隐藏文件

---

#### 模式 3：解压到当前文件夹（简化进度）

**行为：**
1. 启动应用，直接开始解压
2. 解压到归档所在目录
3. 显示进度界面
4. 完成后自动退出

**UI：**
```
┌─────────────────────────────────────┐
│  解压中...          [─][×]          │
├─────────────────────────────────────┤
│  ████████████░░░░░░░░  60%         │
│  当前文件: xxx.txt                  │
│  已完成: 2.1 MB / 3.5 MB           │
└─────────────────────────────────────┘
```

**启动参数：**
```
litepack.exe --extract-here "E:\archive.zip"
```

---

#### 模式 4：解压到同名目录（简化进度）

**行为：**
1. 启动应用，直接开始解压
2. 在归档所在目录创建同名子目录（去掉扩展名）
3. 解压到该子目录
4. 显示进度界面
5. 完成后自动退出

**示例：**
- 归档：`E:\Downloads\del_node_modules.zip`
- 目标目录：`E:\Downloads\del_node_modules\`

**UI：**
```
┌─────────────────────────────────────┐
│  解压中...          [─][×]          │
├─────────────────────────────────────┤
│  ████████████░░░░░░░░  60%         │
│  当前文件: xxx.txt                  │
│  已完成: 2.1 MB / 3.5 MB           │
└─────────────────────────────────────┘
```

**启动参数：**
```
litepack.exe --extract-named "E:\archive.zip"
```

## 4. 技术实现方案

### 4.1 后端改动

#### context_menu.rs

新增三个 verb 注册：

```rust
const VERBS: [(&str, &str, &str); 3] = [
    ("LitePackOpen", "打开(&O)", "--open"),
    ("LitePackExtractTo", "解压到...(\\&E)...", "--extract-to"),
    ("LitePackExtractNamed", "解压到同名目录(&N)", "--extract-named"),
];

// 原有 verb
const VERB_EXTRACT_HERE: (&str, &str, &str) = 
    ("LitePackExtractHere", "解压到当前文件夹(&X)", "--extract-here");
```

#### lib.rs

扩展启动参数解析：

```rust
enum PendingAction {
    Open(String),           // --open <path>
    ExtractHere(String),    // --extract-here <path>
    ExtractTo(String),      // --extract-to <path>
    ExtractNamed(String),   // --extract-named <path>
}
```

#### state.rs

存储待处理操作：

```rust
pub struct PendingAction {
    pub action: PendingActionType,
    pub archive_path: String,
}
```

### 4.2 前端改动

#### App.vue

根据启动参数选择 UI 模式：

```typescript
onMounted(async () => {
  const pending = await takePendingAction();
  if (pending) {
    switch (pending.type) {
      case 'open':
        await handleOpen(pending.path);
        break;
      case 'extract-here':
        await handleExtractHere(pending.path);
        break;
      case 'extract-to':
        await handleExtractTo(pending.path);
        break;
      case 'extract-named':
        await handleExtractNamed(pending.path);
        break;
    }
  }
});
```

#### 新增组件

| 组件 | 用途 |
|------|------|
| `ExtractDialog.vue` | 解压到...对话框（模式 2） |
| `MiniProgress.vue` | 简化进度界面（模式 3、4） |

### 4.3 IPC 命令

复用现有命令，无需新增：

- `list_archive` - 获取归档信息（用于对话框显示）
- `extract_archive` - 执行解压
- `take_pending_extract` - 获取待处理操作（需扩展返回类型）
- `exit_app` - 退出应用

## 7. 风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 注册表路径冲突 | 中 | 使用唯一 verb 名称，避免与 360 等软件冲突 |
| 启动参数解析错误 | 低 | 严格校验参数格式，提供友好错误提示 |
| 磁盘空间计算失败 | 低 | 显示"未知"而非崩溃 |
| 用户取消后状态残留 | 低 | 确保取消后清理临时文件 |
