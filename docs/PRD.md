## 1. 产品概述

### 1.1 产品定位

LitePack 是一款轻量级、跨平台的压缩包管理工具，支持 ZIP 和 7z 格式的压缩、解压和浏览操作。提供桌面 GUI 应用和命令行工具两种使用方式。

### 1.2 产品愿景

为用户提供安全、高效、易用的压缩包管理体验，填补开源生态中轻量级跨格式压缩工具的空白。

### 1.3 核心价值主张

| 价值 | 说明 |
|------|------|
| 轻量 | 无臃肿功能，启动快，占用资源少 |
| 跨平台 | Windows / Linux / macOS 三端支持 |
| 安全 | 内置路径穿越防护、Zip 炸弹检测、密码错误区分 |
| 现代化 | Tauri v2 + Vue 3 技术栈，UI 美观 |
| 开源 | MIT 许可证，完全免费使用 |

## 2. 目标用户

### 2.1 用户画像

| 用户类型 | 描述 | 核心需求 |
|----------|------|----------|
| 普通用户 | 日常解压文件的个人用户 | 简单易用、双击打开、右键解压 |
| 开发者 | 需要批量处理压缩文件的开发者 | CLI 工具、脚本集成、自动化 |
| 系统管理员 | 管理服务器备份和日志归档 | 密码加密、批量操作、可靠稳定 |

### 2.2 使用场景

1. **日常解压**：接收 .zip/.7z 文件，双击打开浏览内容，选择性解压
2. **快速解压**：右键点击压缩文件 → "解压到当前目录"
3. **文件压缩**：选中文件 → 右键压缩 → 选择格式和密码
4. **归档管理**：浏览压缩包内文件结构，搜索特定文件
5. **批量处理**：通过 CLI 脚本批量压缩/解压多个文件
6. **安全传输**：使用 AES-256 加密压缩敏感文件

## 7. 安全设计

### 7.1 路径穿越防护

`safe_join()` 函数验证所有条目路径，拒绝 `..`、绝对路径、盘符前缀、空条目名。

### 7.2 Zip 炸弹检测

| 限制 | 值 |
|------|-----|
| 最大条目数 | 100,000 |
| 最大解压后总大小 | 256 GiB |
| 最大压缩比 | 10,000:1 |

### 7.3 密码安全

- `Error::BadPassword`：密码错误
- `Error::Encrypted`：需要密码
- 密码仅存于内存，不持久化

## 10. 风险评估

### 10.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Tauri v2 API 变更 | 高 | 关注官方更新，及时适配 |
| 7z 格式兼容性 | 中 | 使用成熟的 sevenz-rst 库 |
| WebView2 缺失 | 中 | 安装包捆绑 WebView2 |

### 10.2 产品风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| RAR 格式需求 | 中 | 明确不支持，文档说明 |
| 性能不达标 | 高 | 使用 rayon 并行优化 |
| 安全漏洞 | 高 | 代码审计，安全测试 |
